# 🌦️ WeatherPro – Smart Weather Dashboard

WeatherPro is a modern, responsive, and interactive weather dashboard that delivers real-time weather information for cities across the globe. Built with **HTML5**, **CSS3**, and **Vanilla JavaScript**, the application integrates with the **OpenWeather API** to provide accurate and up-to-date weather data through a clean, intuitive, and user-centric interface.

The project focuses on responsive UI design, asynchronous API integration, dynamic DOM manipulation, and an enhanced user experience with weather-based theme transitions.

---

## ✨ Key Features

- 🌍 Search weather information for any city worldwide
- 🌡️ Real-time temperature and "Feels Like" temperature
- 💧 Live humidity and atmospheric pressure
- 🌬️ Wind speed information
- 👁️ Visibility details
- 🌅 Sunrise and sunset timings
- 🌎 Country identification
- 🎨 Dynamic background themes based on current weather conditions
- 🌙 Light/Dark mode toggle
- ⚡ Fast API response with seamless UI updates
- 📱 Fully responsive layout for desktop, tablet, and mobile devices
